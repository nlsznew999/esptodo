# TeamTask - ระบบจัดการ To-Do List & Kanban Board สำหรับทีม 🚀

ระบบจัดการงานและ To-Do List ของทีมที่ออกแบบมาเพื่อให้เห็นภาพรวมของโปรเจกต์ได้ง่าย พร้อมทั้งมีพื้นที่การทำงานเฉพาะสำหรับสมาชิกแต่ละคนในรูปแบบ **Kanban Board** และรองรับการเปิดเป็น Server เพื่อให้คนในทีมเข้ามาใช้งานร่วมกันได้แบบ Real-time

---

## 🌟 ฟังก์ชันหลัก

### 1. หน้าภาพรวมของทีม (Team Overview)
* **สรุปสถิติงานทั้งทีมแบบ Real-time**: งานทั้งหมด, กำลังทำ, รอตรวจ, เสร็จสิ้น และงานที่เลยกำหนดส่ง (Overdue Alert)
* **การ์ดภาระงานของสมาชิกแต่ละคน (Workload Cards)**: แสดงอัตราความสำเร็จ (Progress Bar), จำนวนงานในแต่ละสถานะของแต่ละคน พร้อมปุ่มคลิกเพื่อเปิดบอร์ด Kanban ของคนนั้นได้ทันทีในคลิกเดียว
* **ตารางงานรวมทั้งทีม (Master Task List)**: สามารถค้นหาด้วยคำสำคัญ (Search), กรองตามสมาชิก, กรองตามความสำคัญ และเปลี่ยนสถานะงานได้โดยตรงจากตาราง

### 2. หน้าของทีมงานแต่ละคน (Personal Kanban Board)
* สมาชิกแต่ละคนมีหน้าพื้นที่ทำงานของตัวเองโดยเฉพาะ
* แถบสลับชื่อสมาชิกด้านบน (Quick Switcher) เลือกดูงานของตนเองหรือเพื่อนร่วมทีมได้สะดวกรวดเร็ว
* 4 คอลัมน์ Kanban: **To Do (รอทำ)**, **In Progress (กำลังทำ)**, **Review (รอตรวจ)**, **Done (เสร็จสิ้น)**
* **ระบบ Drag & Drop**: ลากการ์ดงานและปล่อยลงในคอลัมน์เป้าหมายเพื่อเปลี่ยนสถานะได้ลื่นไหล
* **Quick Add**: ปุ่มเครื่องหมาย `+` ในแต่ละหัวคอลัมน์เพื่อสร้างงานในสถานะนั้นโดยตรง

### 3. ข้อมูลในแต่ละงานครบถ้วน
* 📌 **ชื่องาน (Task Title)**
* 📝 **รายละเอียด (Description / Checklist)**
* 📅 **วันที่ (Start Date)**: วันที่เริ่มงาน
* ⏰ **Deadline (กำหนดส่ง)**: พร้อมระบบคำนวณแจ้งเตือนอัจฉริยะ (แดง = เลยกำหนดส่ง, ส้ม = ครบกำหนดวันนี้/พรุ่งนี้)
* 🏷️ **สถานะงาน (Status)**: To Do, In Progress, Review, Done
* ⚡ **ระดับความสำคัญ (Priority)**: ต่ำ (Low), ปานกลาง (Medium), สูง (High), ด่วนมาก (Urgent)
* 🏷️ **หมวดหมู่ / แท็ก (Tags)**: เช่น Frontend, Backend, Design, QA, Bug

## 🌐 การรันเป็น Server เพื่อให้คนอื่นเข้ามาใช้งานร่วมกัน

### 1. เปิดเซิร์ฟเวอร์บนเครื่องตัวเอง (Local Server)
* **ดับเบิ้ลคลิกไฟล์ [**`start-server.bat`**](file:///c:/Users/User/Desktop/Team%20to%20do/start-server.bat)**
* หน้าต่างดำจะเปิดขึ้นมา และแสดงที่อยู่ IP ของคุณ:
  * บนเครื่องคุณ: `http://localhost:8080`
  * บนเครื่องเพื่อนหรือมือถือในวง Wi-Fi เดียวกัน: `http://<IP-ของคุณ>:8080` (เช่น `http://192.168.0.78:8080`)
* ข้อมูลทั้งหมดจะถูกบันทึกลงในไฟล์ [`data/database.json`](file:///c:/Users/User/Desktop/Team%20to%20do/data/database.json) อัตโนมัติ

### 2. แชร์ออกสู่อินเทอร์เน็ตให้คนนอกเข้าใช้งาน (Cloudflare Tunnel)
* เมื่อเปิด `start-server.bat` แล้ว
* **ดับเบิ้ลคลิกไฟล์ [**`share-internet.bat`**](file:///c:/Users/User/Desktop/Team%20to%20do/share-internet.bat)**
* ระบบจะสร้างลิงก์สาธารณะ HTTPS เช่น `https://random-words.trycloudflare.com`
* นำลิงก์นี้ส่งให้เพื่อนหรือทีมงานทุกคนเข้ามาทดลองใช้งานได้จากทุกที่ทั่วโลกทันที!

### 3. การนำขึ้น Cloud ถาวร (Render.com / Glitch)
* ดูคำแนะนำอย่างละเอียดในไฟล์ [**`DEPLOYMENT_GUIDE.md`**](file:///c:/Users/User/Desktop/Team%20to%20do/DEPLOYMENT_GUIDE.md)
