# 🚀 คู่มือการนำ TeamTask ขึ้น Server (Cloud Hosting & Sharing Guide)

เพื่อให้คนอื่นหรือเพื่อนร่วมทีมสามารถเข้ามาทดลองใช้ผ่านอินเทอร์เน็ต และทุกคนสามารถ **เพิ่ม/แก้ไข/ย้ายงานของแต่ละคนร่วมกันแบบ Real-time** ได้ มีทางเลือกที่ง่ายและฟรี 3 วิธี ดังนี้ครับ:

---

## 🌟 วิธีที่ 1: นำขึ้น Render.com (ฟรี 100% แนะนำที่สุด ได้ URL ประจำตัว)

[Render.com](https://render.com) เป็นผู้ให้บริการ Cloud Hosting ยอดนิยม ใช้งานฟรี เหมาะกับระบบนี้ที่สุด เพราะรองรับ `server.js` และฐานข้อมูล JSON ได้ทันที

### ขั้นตอนการทำ:
1. **นำโค้ดขึ้น GitHub**:
   * เข้าเว็บ [GitHub.com](https://github.com) แล้วสร้าง Repository ใหม่ (เช่นชื่อ `team-task`)
   * อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ Repository นั้น
2. **สร้าง Web Service บน Render**:
   * สมัคร/เข้าสู่ระบบที่ [Render.com](https://render.com)
   * กดปุ่ม **"New +"** มุมขวาบน -> เลือก **"Web Service"**
   * เชื่อมต่อกับ GitHub Repository ที่เพิ่งสร้าง
3. **ตั้งค่า (Render จะตรวจพบอัตโนมัติจากไฟล์ `render.yaml`)**:
   * **Name**: ตั้งชื่อเว็บตามต้องการ เช่น `my-team-todo`
   * **Environment**: `Node`
   * **Build Command**: เว้นว่างไว้ หรือปล่อยตามค่าเริ่มต้น
   * **Start Command**: `node server.js`
   * **Plan**: เลือก `Free`
4. กด **"Create Web Service"**
5. รอประมาณ 1-2 นาที คุณจะได้ลิงก์ เช่น:
   ```
   https://my-team-todo.onrender.com
   ```
   👉 ส่งลิงก์นี้ให้เพื่อนร่วมทีมหรือคนอื่นเข้ามาลองใช้งานได้เลย ทุกคนจะเห็นงานอัปเดตตรงกันทันที!

---

## ⚡ วิธีที่ 2: ใช้ Glitch.com (เร็วและง่ายที่สุด ไม่ต้องใช้ Git หรือพิมพ์คำสั่งใดๆ)

หากไม่ต้องการใช้ GitHub หรือติดตั้งโปรแกรมใดๆ สามารถเปิดบน [Glitch.com](https://glitch.com) ได้ใน 3 นาที:

1. เข้าเว็บ [glitch.com](https://glitch.com) แล้วสมัครบัญชีฟรี
2. กด **"New Project"** -> เลือก **"glitch-hello-node"**
3. ลบไฟล์เดิมในโปรเจกต์ออก แล้วอัปโหลดไฟล์จากโฟลเดอร์นี้เข้าไป:
   * `server.js`
   * `package.json`
   * `index.html`
   * โฟลเดอร์ `css/` และ `js/`
   * โฟลเดอร์ `data/database.json`
4. Glitch จะเริ่มรันเซิร์ฟเวอร์ให้อัตโนมัติทันที
5. กดปุ่ม **"Share"** หรือ **"Preview"** -> **"Open live site"** เพื่อรับ URL (เช่น `https://cool-project-name.glitch.me`) นำไปแชร์ให้คนอื่นทดลองใช้งานได้ทันที

---

## 💻 วิธีที่ 3: รัน Server บนเครื่องตัวเอง แล้วแชร์ให้คนอื่นเข้า (ไม่ต้องสมัครเว็บใดๆ)

### แบบที่ 3.1: แชร์ให้คนในวง Wi-Fi / ออฟฟิศเดียวกัน
1. ดับเบิ้ลคลิกไฟล์ [**`start-server.bat`**](file:///c:/Users/User/Desktop/Team%20to%20do/start-server.bat) บนเครื่อง
2. หน้าต่างเซิร์ฟเวอร์จะเปิดขึ้นมา และบอก IP ของเครื่องคุณ เช่น `http://192.168.1.50:8080`
3. เพื่อนที่ต่อ Wi-Fi เดียวกัน สามารถพิมพ์ IP ดังกล่าวในโทรศัพท์หรือคอมพิวเตอร์เพื่อเข้าใช้งานได้ทันที

### แบบที่ 3.2: แชร์ออกอินเทอร์เน็ตทั่วโลกด้วย Cloudflare Tunnel (ฟรีและปลอดภัย)
หากต้องการให้คนนอกบ้าน/นอกออฟฟิศเข้าได้โดยใช้เซิร์ฟเวอร์บนเครื่องคุณ:
1. ดาวน์โหลด [Cloudflare Tunnel (cloudflared)](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)
2. รันคำสั่งใน PowerShell:
   ```powershell
   cloudflared tunnel --url http://localhost:8080
   ```
3. Cloudflare จะสร้างลิงก์ชั่วคราวให้ฟรี เช่น `https://random-words.trycloudflare.com` สามารถส่งลิงก์นี้ให้คนอื่นเข้ามาใช้งานได้ทันที

## 🔄 ระบบการซิงค์ข้อมูลทำงานอย่างไร?

* **เมื่อต่อกับ Server (Online)**:
  * แถบด้านบนของหน้าเว็บจะขึ้นป้าย **🟢 Online (Server ซิงค์กับทีม)**
  * ระบบจะดึงและบันทึกข้อมูลไปที่ส่วนกลาง (`data/database.json`)
  * มีระบบ **Auto-Sync ทุก 4-5 วินาที**: เมื่อคนหนึ่งเพิ่มงานหรือเลื่อนสถานะใน Kanban Board หน้าจอของเพื่อนร่วมทีมจะอัปเดตตามโดยอัตโนมัติ
* **เมื่อเปิดไฟล์ธรรมดา (Offline)**:
  * แถบด้านบนจะขึ้นป้าย **🟡 Offline (บันทึกในเครื่อง)** ข้อมูลจะถูกเก็บใน LocalStorage ของเบราว์เซอร์นั้นๆ
